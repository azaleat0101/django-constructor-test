# Конструктор тестов

## Назначение

Приложение для создания и прохождения тестов в интерактивном режиме.
Позволяет формировать тест с названием и описанием, задавать вопросы
с вариантами ответов, проверять ответы пользователя и автоматически
выставлять оценку по проценту правильных ответов.

На текущем этапе (ПР1) программа работает в консольном режиме:
пользователь запускает `main.py`, отвечает на вопросы через стандартный
ввод и получает итоговый результат.

## Целевая аудитория

- Преподаватели и методисты, которым нужно быстро собирать тесты.
- Студенты и учащиеся, проходящие проверочные задания.
- HR-специалисты, проводящие первичное тестирование кандидатов.

## Предметная область

Образовательные и проверочные онлайн-сервисы. Предметная область
включает создание тестов, хранение вопросов и вариантов ответов,
прохождение тестирования и подсчёт результатов.

## Основные сущности

- Тест (название, описание, автор, дата создания)
- Вопрос (текст, тип, принадлежность к тесту)
- Вариант ответа (текст, признак правильности)
- Пользователь (имя, роль: автор или участник)
- Результат прохождения (пользователь, тест, количество баллов)

## Основные функции

- Создание теста с названием и описанием.
- Проверка корректности введённого названия теста.
- Формирование вопроса с вариантами ответов.
- Интерактивный ввод ответа пользователем через `input()`.
- Проверка ответа пользователя (без учёта регистра и лишних пробелов).
- Подсчёт результата и выставление оценки по проценту правильных ответов.

## Реализовано на ПР1

Начальный сценарий (`main.py`) включает пять функций:

1. `get_test_info()` — выводит информацию о тесте (название, описание,
   количество вопросов).
2. `validate_title()` — проверяет корректность названия теста
   (длина от 3 до 100 символов, обрезка пробелов).
3. `ask_question()` — выводит вопрос с вариантами ответов и
   возвращает ответ пользователя, введённый через `input()`.
4. `check_answer()` — сравнивает ответ пользователя с правильным
   без учёта регистра и лишних пробелов.
5. `calculate_score()` — вычисляет процент правильных ответов и
   выставляет оценку («Отлично», «Хорошо», «Удовлетворительно»,
   «Неудовлетворительно»).

Программа задаёт пользователю три вопроса, проверяет ответы
и выводит итоговый результат.

Использованные конструкции Python: простые типы данных, операции,
преобразование типов, ветвления (`if / elif / else`), функции,
импорт модулей (`from datetime import datetime`), ввод и вывод
(`input()` / `print()`).
