# Конструктор тестов

Консольное приложение для создания тестов, их прохождения
и автоматической проверки результатов.

## Возможности

- создание теста с названием и описанием;
- добавление вопросов с вариантами ответов;
- прохождение теста с проверкой каждого ответа;
- автоматический подсчёт процента и выставление оценки;
- поиск тестов по подстроке в названии;
- сортировка тестов по названию;
- отбор тестов по количеству вопросов;
- отмена попытки прохождения;
- сохранение данных в JSON-файлах.

## Структура проекта

- `main.py` — точка входа и меню;
- `test_bank.py` — работа с тестами и вопросами;
- `attempts.py` — прохождение и результаты;
- `storage.py` — сохранение и загрузка JSON;
- `utils.py` — безопасный ввод;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Требования

- Python 3.10+
- pytest
- flake8

Установка зависимостей:

    pip install -r requirements.txt

## Запуск программы

    python main.py

## Запуск тестов

    pytest

## Проверка качества кода

    flake8
