# Конструктор тестов

Консольное приложение для создания тестов, их прохождения
и автоматической проверки результатов.

## Возможности

- создание теста с названием и описанием;
- добавление вопросов с вариантами ответов;
- прохождение теста с проверкой каждого ответа;
- автоматический подсчёт процента и выставление оценки;
- поиск тестов по подстроке в названии;
- сортировка тестов по названию;
- отбор тестов по количеству вопросов;
- поиск пользователей по имени;
- удаление попытки прохождения;
- сохранение данных в JSON-файлах между запусками.

## Предметная область

Система тестирования знаний: пользователи проходят тесты,
состоящие из вопросов, и получают оценку. Все сущности
представлены объектами соответствующих классов.

## Основные сущности

### Question — вопрос теста

- `text` — текст вопроса;
- `options` — список вариантов ответа;
- `correct_answer` — правильный вариант.

Методы:
- `check_answer(user_answer)` — проверка ответа;
- `to_data()` / `from_data()` — сериализация.

### Test — тест

- `id`, `title`, `description`;
- `questions` — список объектов `Question`.

Методы:
- `add_question(question)`;
- `questions_count` — количество вопросов;
- `validate_title(title)` — статический метод проверки названия.

### User — пользователь

- `id`, `name`.

### Attempt — попытка прохождения

- `id`, `test: Test`, `user: User`, `correct`, `total`;
- `percent`, `grade`, `date`.

Методы:
- `grade` — свойство с оценкой по проценту;
- `to_data()` / `from_data(tests, users)` — сериализация
  с восстановлением связей.

## Взаимодействие объектов

- `Test` содержит коллекцию объектов `Question`.
- `Attempt` хранит ссылки на объект `Test` и объект `User`.
  В JSON сохраняются их `id`, а при загрузке связи
  восстанавливаются (`attempt.test is tests[0]`).

## Структура проекта

- `main.py` — точка входа и меню;
- `storage.py` — сохранение и загрузка JSON;
- `utils.py` — безопасный ввод;
- `models/` — пакет предметной области:
  - `questions.py` — класс `Question`;
  - `tests.py` — класс `Test` и функции обработки;
  - `users.py` — класс `User` и функции обработки;
  - `attempts.py` — класс `Attempt` и функции обработки;
- `data/` — JSON-файлы данных;
- `tests/` — автотесты pytest.

## Требования

- Python 3.10+
- pytest
- flake8

Установка зависимостей:

    pip install -r requirements.txt

## Запуск программы

    python main.py

    pytest -v
